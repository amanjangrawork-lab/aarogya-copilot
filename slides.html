Aarogya Copilot

Fragmented prescriptions, labs & discharge papers → one plain-language health story, on your phone, in your language.

Problem: 0% interoperable records for most patients · 3–5× repeat tests · paper files + bilingual/handwritten Rx.
Solution: upload → OCR → extract → explain → timeline → FHIR/ABHA — offline-first, zero backend.

Live demo: open index.html → click 💊/🧪/🏥 demo buttons → Summary → Timeline → FHIR export. Print this page to PDF for submission.

1 · Medical record intelligence & OCR

  • pdf.js text layer (digital PDFs) + Tesseract.js fallback (scans/photos, eng+hin+tel+tam)
  • Medicines: 60+ Indian drug list + Tab/Cap/Syp regex (dose + OD/BD/TDS/1-0-1 + duration)
  • Labs: 14 tests with LOINC (HbA1c, CBC, lipid, creatinine, TSH…), flag high/low/borderline
  • Diagnoses → ICD-10 + SNOMED CT · dates · doctor/facility · doc-type classifier

2 · Plain-language summary + timeline

  • Headline + flagged values with “what it means” in EN / HI / TE / TA
  • Medicines explained, questions-to-ask-doctor, next steps — hedged, safe wording
  • Optional Gemini 1.5 Flash second opinion (key optional, offline always works)
  • Unified timeline: prescriptions + labs + discharge + wellness (BP/sugar/weight)

3 · ABDM-ready by design

  • FHIR R4 Bundle: Patient(ABHA id) + Observation(LOINC) + MedicationRequest + Condition(ICD-10/SNOMED) + DocumentReference
  • Mock ABHA link (OTP 123456) + mock ABDM import → swap for real gateway calls
  • Aligns with Altrix UHIN vision: ABHA-first identity, consent artifact, rural reach

Export the bundle → import it back. That’s interoperability in one click.

4 · Safety, impact & ask

  • ⚠️ Educational-only disclaimers, no dose changes, emergency banner; data stays in browser
  • Impact: fewer repeat tests, better adherence, calmer doctor visits — especially for elders + regional languages
  • Next (R2): RxNorm, handwriting model, HAPI FHIR server + ABDM sandbox, reminders, caregiver consent-share
